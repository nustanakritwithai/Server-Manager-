Admin Control Center

Game test client

Stay signed in saves an expiring session token in this browser. It does not save the password. GitHub Pages storage is shared by every site on https://nustanakritwithai.github.io, so leave this on only for a trusted personal device. Uncheck it to keep the session in memory for this tab only. The server removes surrounding spaces and hidden characters from a pasted password.

Not signed in.

Advanced: X-Admin-Token

The box starts unchecked. Connect keeps the token in memory for this tab unless Remember token on this device is checked; then Connect saves it in this browser profile and later visits load it. Clear token removes it. Anything else served from this page’s origin can read a saved token. Pasted tokens drop surrounding spaces, line breaks, non-breaking spaces, and zero-width characters. The token is not written to session storage, cookies, the URL, or the console. The API still checks the header.

Dashboard

Liveness probes come from /health and /health/ready. Counts come from GET /v1/admin/dashboard. Measured queue, worker, disk, and API checks are on the Monitoring tab. CPU and memory stay NOT INSTRUMENTED.

Snapshot control

Create, list, get, and inspect use the Phase 2 admin API. Restore sends confirm: true only after inspection and an explicit confirmation.

Restore

This replaces the live simulation. The server writes a SAFETY snapshot, pauses the worker, checks the checksum, and applies the payload. This page does not perform those steps itself.

Monitoring
